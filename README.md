# AMHLink
<!-- TL;DR: Offline-first mobile utility apps for Android and iOS -->

AMHLink builds offline-first mobile utility apps for Android and iOS. Each app focuses on a single daily task, runs locally on your device without mandatory accounts, and contains no advertising SDKs or third-party analytics trackers.

## How We Work

- **Local by default**: Core features (speech synthesis, phrase boards, reading databases, and document parsing) run on-device so they work without a network connection.
- **Data minimization**: When a feature needs the network, payloads are encrypted on-device and kept only briefly.
- **Source & security**: Our application repositories are maintained privately. For support, bug reports, or security disclosures, contact [support@amhlink.com](mailto:support@amhlink.com).
